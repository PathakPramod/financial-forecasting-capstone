# financial-forecasting-capstone
Multi-Horizon Time Series Forecasting Framework for Asset Management Companies (Financial Market) using Deep Learning

```text
financial-forecasting-capstone/
├── data/
│   ├── raw/            # Unprocessed source extractions from Yahoo Finance & FRED
│   └── processed/      # Structured performance matrices, holdings, & sentiment layers
├── notebooks/          # Exploratory data analyses, distribution checks, & linear baselines
├── src/
│   ├── models/         # Deep learning architectures (LSTM & attention-based Transformer)
│   └── features/       # Mathematical transformation pipelines (RSI, MACD, FinBERT vectors)
└── README.md           # System configuration, deployment rules, and dependency tracking
```
